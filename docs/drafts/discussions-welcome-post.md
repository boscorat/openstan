# Welcome to openstan Discussions

Welcome to the openstan community! This is the place to ask questions, share
ideas, and connect with other users and contributors.

## Quick links

- **Documentation:** [openstan.org](https://openstan.org)
- **Getting started:** [Quick Start guide](https://openstan.org/quickstart/)
- **Bug reports:** [GitHub Issues](https://github.com/boscorat/openstan/issues)
- **Source code:** [GitHub](https://github.com/boscorat/openstan)

## Categories

| Category | Use for |
|----------|---------|
| **Announcements** | Release updates, project news |
| **Q&A** | Questions about installation, usage, troubleshooting |
| **Adding a New Bank** | Request a new bank, discuss bank support, or ask how to add a bank configuration yourself. Vote on existing requests to help us prioritise. |
| **Ideas** | Feature requests and suggestions |
| **Show & Tell** | Share how you use openstan |

## Guidelines

1. **Search first** — your question may already have an answer.
2. **Be specific** — include your OS, openstan version, and steps to reproduce.
3. **One topic per thread** — keeps conversations focused and searchable.
4. **Be kind** — we're all here to help each other.

## Response time

We aim to respond within **7 days**. This is a side project maintained alongside
full-time work, so please be patient. If something is urgent, say so in your
post.
