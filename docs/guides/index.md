# Guides

Learn how to use every feature of openstan with our step-by-step guides.

## Getting Started

- [**Project Management**](./project-management.md) – Create, switch between, and manage openstan projects. Covers the project selector bar, creation wizard, adding existing projects, and navigation shortcuts.
- [**Import Statements**](./import-statements.md) – Build a queue of bank statement PDFs and run the import process. Add individual files or folders, remove duplicates, and track real-time batch progress.

## Working with Imported Data

- [**Import Results**](./import-results.md) – Review openstan import results across Success, Review, and Failure tabs. View per-file debug output alongside the original PDF, then commit or abandon your batch.
- [**Project Info**](./project-info.md) – View summary statistics in openstan: total transactions, statement count, per-account breakdowns, date range, and automatically detected statement coverage gaps.
- [**Run Reports**](./run-reports.md) – Build custom transaction reports in openstan with the no-code report builder. Set filters, group by date or account, add aggregations, and export results.

## Exporting & Sharing

- [**Export Data**](./export-data.md) – Export committed transaction data from openstan to Excel, CSV, or JSON. Choose a flat transactions table or full star-schema dataset with configurable presets.
- [**Anonymise**](./anonymise.md) – Redact bank statement PDFs for safe sharing using openstan. Scramble text, force replacements, preserve structural phrases — single file or batch folder mode.
- [**Advanced Export**](./advanced-export.md) – Create spec-driven custom exports in openstan using TOML files. Filter by account, statement, or date range. Define output shape with a reusable export spec.

## Administration & Support

- [**Admin Panel**](./admin.md) – Admin panel for project operations, logging, and diagnostics in openstan. View logs, enable verbose mode, delete or remove projects, and reset the app database.
- [**Logging & Debugging**](./logging.md) – Enable verbose mode to diagnose import failures, parsing anomalies, and export errors. Access application and project logs for support troubleshooting.
- [**About openstan**](./about.md) – The openstan About dialog shows your installed version, a link to the GitHub repository, the LGPL-3.0 licence, and the bank_statement_parser library version.
