# About

The **About** dialog shows the currently installed version of openstan, links
to the project's GitHub repository and website, the version of the underlying
[bank_statement_parser](https://boscorat.github.io/bank_statement_parser/)
library, and the full LGPL-3.0 licence text. Use it to confirm your installed
version before [reporting an issue](../community.md) or checking whether an
[upgrade](../installation.md#upgrading) is available.

---

## Opening the About dialog

Click the **About** button in the top-right corner of the application title bar.

![About dialog](../assets/screenshots/about.png#only-light)
![About dialog](../assets/screenshots/dark/about.png#only-dark)

## Contents

| Item | Description |
|---|---|
| **Logo and tagline** | The openstan logo, theme-aware (adapts to light/dark mode). |
| **Version** | The currently installed version of openstan (e.g. `0.1.2`). |
| **openstan.org** | Link to the openstan website. |
| **GitHub repository** | Link to the openstan source code on GitHub. |
| **Powered by bank\_statement\_parser** | The version of the underlying parsing library in use. |
| **bank\_statement\_parser repository** | Link to the BSP source code on GitHub. |
| **Copyright** | © 2025–2026 Jason Farrar |
| **Licence** | Link to the full LGPL v3.0 or later licence text. |

All links open in your system's default web browser.

## Finding your version number

The version shown in the About dialog is the authoritative reference for your
installation. Include it when:

- [Reporting a bug](https://github.com/boscorat/openstan/issues/new?template=bug-report.yml)
  on GitHub — helps pinpoint whether the issue is already fixed in a newer
  release.
- Checking the [GitHub Releases](https://github.com/boscorat/openstan/releases)
  page to see if an [upgrade](../installation.md#upgrading) is available.
- Sharing your setup in a [GitHub Discussion](https://github.com/boscorat/openstan/discussions)
  so others can give accurate advice.
